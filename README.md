# Linguagens de Programação · 11.º IG

Materiais de Linguagens de Programação do 11.º ano do Curso Profissional de Técnico/a de Informática de Gestão, em 2026/2027. Podes lê-los antes de serem dados na aula.

## Por onde começar

As áreas estão pela ordem do ano. Começa pela primeira, [Programação orientada a objetos](01-programacao-orientada-objetos/README.md). Cada tema tem estes documentos:

- o guia, com a matéria por escrito, para estudares;
- o laboratório, para fazeres no computador, passo a passo;
- a ficha de exercícios, para treinares sozinho.

Em cada área, os guias estão na pasta da área, os laboratórios na pasta `laboratorios` e as fichas na pasta `exercicios`. Cada uma destas pastas tem um índice que explica o que é esse tipo de documento.

Se tens dificuldades nas bases do 10.º ano, faz o [diagnóstico](avaliacoes/diagnostico-inicial.md) e a [ficha de recuperação](01-programacao-orientada-objetos/exercicios/bridge-raciocinio.md). São opcionais e não têm entrega.
