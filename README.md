# Linguagens de Programação · 11.º IG

Materiais de Linguagens de Programação do 11.º ano do Curso Profissional de Técnico/a de Informática de Gestão, em 2026/2027. Cada material é publicado quando fica pronto, e podes lê-lo antes de ser dado na aula.

## Por onde começar

Abre a área [Programação orientada a objetos](01-programacao-orientada-objetos/README.md), que tem os temas e diz por que ordem a turma os está a dar. Cada tema tem três tipos de documento:

- o guia, para ler e estudar;
- o laboratório, para seguir passo a passo no computador, sem precisares de abrir o guia;
- a ficha de exercícios, para praticares sozinho.

## Como estudar

Lê o guia antes de escrever código: primeiro a explicação, depois o exemplo guiado. Quando aparecer uma tabela com os valores antes e depois de cada passo, segue os passos pela ordem. Antes de correres um programa, escreve a tua previsão. É aí que percebes se a ideia ficou entendida. Se o resultado for diferente, tenta explicar a diferença, em vez de mudares números ao acaso. Podes sempre voltar às explicações e pedir uma pista ao professor.

Os diagramas e o pseudocódigo servem para pensar sobre o programa, e não se executam. Um excerto de código depende de outras partes do ficheiro: o guia diz quando um programa está completo e se pode executar.

Nos exercícios, usa só os dados que eles dão, que são inventados. As resoluções dos exercícios não estão aqui, porque se trabalham na aula.
